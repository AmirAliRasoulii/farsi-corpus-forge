# دستورالعمل ارزیابی کیفیت فارسی کاندیدای داده سالم

شما کیفیت زبان فارسی و روانی متن کاندیدای داده سالم را ارزیابی می‌کنید.

## وظیفه:
بررسی کنید که آیا متن تولید شده فارسی طبیعی، روان و بدون گسست نگارشی است یا خیر.

## نمره‌دهی (۱ تا ۵):
- `fluency`: روانی و رعایت دستور زبان فارسی.
- `naturalness`: تناسب با زبان فارسی طبیعی ایران.
- `conversion_success`: موفقیت ساختار در ارائه یک پیام منسجم و معنادار.

## خروجی (فقط JSON معتبر):
```json
{
  "fluency": 1,
  "naturalness": 1,
  "conversion_success": 1,
  "is_persian": true,
  "flags": [],
  "reason": "توضیح کوتاه به فارسی"
}
```
